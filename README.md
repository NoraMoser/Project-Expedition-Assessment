## Assignment

This app is a simple tool for browsing travel destinations offered by Project Expedition. It was built quickly as a prototype and it shows. Your job is to take it from here — make it something you'd be comfortable owning in production.

Use a **branch-per-section** workflow. Create a new branch for each section below and open a PR (or be ready to walk through your commits).

### Section 1: Project Setup

This project is missing the development infrastructure a real codebase needs. Set it up the way you would for a team.

### Section 2: Database & API

The API layer needs work. The app should be backed by a real database with a properly designed API. Think about how a production API should handle querying, filtering, and edge cases.

### Section 3: User Interface

Review the existing UI code. There are bugs, structural issues, and missing functionality. Improve it to the standard you'd expect from a production application. The UI should give users a good experience browsing and finding destinations.
